# Электронная библиотека

# Описание проекта
Система электронной библиотеки, где можно смотреть информацию о книгах и авторах.
Есть поиск по названию, жанру и автору.
Админ может добавлять новые книги, а обычные пользователи — только смотреть.
Сделана проверка на уникальность книг и авторов, а также логика с разными изданиями:
для художественных допускаются разные издательства, для учебников — только разные переиздания.

# Функции системы
Получение информации о книге.
Поиск по названию книги, жанру или автору.
Получение информации об авторе, включая биографию и список произведений.
Добавление книг доступно толькwо администратору.
Проверка уникальности по полям: название, автор, год выпуска, издательство.
Поддержка изображений и файлов книги.

## Установка и запуск

#Установка необходимых библиотек

pip install django
pip install djangorestframework
pip install pillow

#Выполнение миграций и запуск сервера

python manage.py makemigrations
python manage.py migrate
python manage.py runserver

#Тесты запускаются командой

python manage.py test
